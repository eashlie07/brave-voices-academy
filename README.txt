BRAVE VOICES ACADEMY — REWORKED STATIC SITE

Files:
- index.html
- style.css

This version uses HTML + CSS only.
There are NO JavaScript files and NO <script> tags.

To publish:
1. Replace your current index.html with this index.html.
2. Replace your current style.css with this style.css.
3. Keep the files in the same folder.
4. Commit and push to your existing GitHub repository as you normally do.

The Parks & Recreation registration button currently points to:
https://secure.rec1.com/CO/woodland-park-co/catalog

Before publishing future sessions, update the dates in the "CURRENT CLASS" card in index.html.

If you later want photos, a logo, social links, or additional classes, those can be added without adding JavaScript.
